# /migration — промпт-пакет для ИИ-агента

Набор инструкций для переноса B2B-карточки товара Homtree из этого прототипа
в официальный `medusajs/b2b-starter-medusa` (Medusa v2).

## Порядок чтения

| Файл | Назначение | Кому |
| --- | --- | --- |
| `AGENT_PROMPT.md` | Главный промпт. Задача, роль, инварианты, критерии приёмки. | Дать агенту первым — это его системная инструкция. |
| `MEDUSA_MAPPING.md` | Маппинг полей прототипа на реальные поля Medusa v2 и B2B-модулей. | Читать перед написанием адаптера данных. |
| `FILE_MAP.md` | Куда переносить каждый файл, замены импортов и shadcn → `@medusajs/ui`. | Читать перед копированием кода. |
| `TOKENS.md` | Дизайн-токены, Tailwind v4 → v3, шрифты, замена классов. | Читать перед правкой стилей. |
| `CHECKLIST.md` | Приёмка: 10 блоков проверок + типовые ошибки. | Проходить в конце, перед сдачей. |

## Как запускать

Передать агенту одним сообщением:

```
Прочитай migration/AGENT_PROMPT.md и выполни описанную в нём задачу.
Опорные документы: migration/MEDUSA_MAPPING.md, migration/FILE_MAP.md,
migration/TOKENS.md. По завершении пройди migration/CHECKLIST.md
и отчитайся по каждому пункту.
```

## Что должно получиться

Компонент `HtOrder`, встроенный в `ProductTemplate` starter'а:

- одна общая оптовая сетка вместо трёх в строках вариантов;
- форма-итог: метрики партии · загрузка контейнера 20FT/40HQ · итог без НДС + CTA;
- sticky-панель: 3 колонки на desktop, компактная строка с раскрывающимся листом на mobile;
- данные только из Medusa API, без моков.
