## A. Сборка и типы

- [ ] `cd storefront && yarn build` завершается без ошибок.
- [ ] `npx tsc --noEmit` — 0 ошибок.
- [ ] В `ht-order/` нет ни одного `any` и ни одного `@ts-ignore`.
- [ ] Ни один файл не импортирует `lib/b2b/mock-data`.

      (все алиасы прототипа заменены на алиасы starter'а).

- [ ] `package.json` не получил `shadcn`, `@radix-ui/*` и прочих зависимостей прототипа.

## B. Данные из Medusa

- [ ] Цены приходят из `calculated_price`, не из `variant.prices` (deprecated в v2).
- [ ] Запрос товара содержит `fields` с `*variants.calculated_price` и
      `+variants.inventory_quantity`.
- [ ] `region_id` / `country_code` передаются в запрос — иначе `calculated_price` = `null`.
- [ ] Все суммы трактуются в минорных единицах и делятся на 100 ровно один раз,
      в точке форматирования.
- [ ] Валюта берётся из `calculated_price.currency_code`, а не захардкожена как `CNY`.
- [ ] Отсутствующий `calculated_price` не роняет страницу — вариант рендерится
      как «Цена по запросу».
- [ ] Логистические метрики читаются из `variant.metadata` с фолбэком:
      нет `volume_m3` / `gross_weight_kg` → блок загрузки контейнера скрыт,
      а не показывает `NaN` или `0%`.

## C. Оптовая сетка (главное требование)

- [ ] В строках вариантов НЕТ раскрывающейся оптовой сетки — ни в одной из трёх.
- [ ] Есть ровно ОДНА общая сетка под списком вариантов.
- [ ] Общая сетка переключается на активный вариант при вводе количества.
- [ ] Активная ступень визуально подсвечена и совпадает с ценой за ед. в строке варианта.
- [ ] Сетка скрыта для гостя и для retail-покупателя (только B2B-контекст).
- [ ] Ступени берутся из price rules `quantity` (`gte`/`lte`), а не из моков.

## D. Форма-итог: логика

- [ ] «Позиций в заявке» = число вариантов с `qty > 0` из общего числа вариантов.
- [ ] «Единиц фасовки» = сумма количеств.
- [ ] Вес нетто / брутто считается из `metadata.net_weight_kg` / `gross_weight_kg`.
- [ ] «Объём партии» считается из `metadata.volume_m3 × qty`.
- [ ] «Паллетомест» = `ceil(qty / units_per_pallet)`, суммируется по вариантам.
- [ ] «Готовность партии» = максимум `lead_time_days` среди выбранных вариантов.
- [ ] Загрузка контейнера: процент = max(объём%, вес%) относительно 20FT / 40HQ,
      корректно переключается на 40HQ при переполнении 20FT.
- [ ] Прогресс-бар загрузки не превышает 100% визуально при перегрузе,
      но текстом сообщает о превышении.
- [ ] «Итого без НДС» = сумма `unit_amount × qty` по всем строкам.
- [ ] «Экономия по сетке» = `Σ(base_amount − tier_amount) × qty`, скрыта при нуле.
- [ ] Пустое состояние (ничего не выбрано): все метрики «—», «Итого» = 0,
      кнопка «Добавить в заявку» задизейблена.

## E. Форма-итог: поведение

- [ ] «Добавить в заявку» вызывает server action, а не клиентский `fetch` с токеном.
- [ ] Кнопка показывает состояние загрузки и блокируется на время запроса.
- [ ] Повторный быстрый двойной клик не создаёт две line item'а.
- [ ] Ошибка от Medusa показывается пользователю текстом, а не молча логируется.
- [ ] Успешное добавление сбрасывает количества и обновляет корзину в шапке.
- [ ] «Очистить» сбрасывает все количества без обращения к API.
- [ ] «Запросить котировку» ведёт на штатный quote-флоу starter'а
      (`/account/quotes` / `createQuote`), а не заглушка.
- [ ] Гость видит CTA «Войти для оптовых цен» вместо «Добавить в заявку».

## F. Desktop-раскладка (≥1024px)

- [ ] Форма-итог = 3 колонки: метрики партии · логистика · итог и CTA.
- [ ] Колонки разделены вертикальными границами, как в референсе.
- [ ] Ширина не ломается на 1024, 1280, 1440, 1920.
- [ ] Sticky-панель прилипает к низу при скролле и не перекрывает футер.
- [ ] Sticky-панель не дублирует CTA, когда статичный блок уже виден в вьюпорте.
- [ ] Цены и количества выровнены по правому краю и используют `.ht-numeric`.
- [ ] Длинная сумма (`CN¥20 163,00`) не переносится и не обрезается.

## G. Mobile-раскладка (≤767px)

- [ ] Три колонки превращаются в вертикальный стек, ничего не обрезано.
- [ ] Sticky-панель внизу = компактная строка: «Итого» + «Добавить в заявку».
- [ ] Тап по «детали» раскрывает лист со всеми метриками партии и логистикой.
- [ ] Лист закрывается по кнопке, по тапу вне и по `Escape`.
- [ ] Учтён `env(safe-area-inset-bottom)` — панель не заходит под home indicator iOS.
- [ ] Нет горизонтального скролла страницы на 320px, 375px, 390px, 414px.
- [ ] Все интерактивные элементы ≥44×44px.
- [ ] Степперы количества удобно нажимаются одной рукой, `inputMode="numeric"`.
- [ ] Sticky-панель не перекрывает последний вариант в списке (есть нижний отступ).

## Типовые ошибки при этом переносе

1. `calculated_price` = `null`, потому что не передан `region_id` → цены нули.
2. Деление на 100 дважды (в адаптере и в форматтере) → цена в 100 раз меньше.
3. Копирование `@theme inline` в Tailwind v3 → сборка падает.
4. Токены без префикса `--ht-` → ломаются штатные корзина и чекаут.
5. Inter без `cyrillic` → русские подписи в системном шрифте.
6. Sticky-панель `fixed` без нижнего `padding` на контейнере → перекрывает контент.
7. Оптовая сетка оставлена и в строке варианта, и общая → дублирование, ровно то,
   что требовалось убрать.
8. Добавление в корзину клиентским `fetch` с publishable key → потеря `cart_id`
      из cookies и утечка ключа.
